SwiftType

SwiftType is a modern web-based typing training platform designed to help users improve their typing speed, accuracy, and overall keyboard skills through interactive lessons, tests, and performance tracking.

Features

- Typing speed tests
- Accuracy tracking
- Real-time WPM calculation
- User authentication and accounts
- Progress monitoring
- Interactive typing lessons
- Responsive design for desktop and mobile devices
- Modern and user-friendly interface

Technologies Used

Backend

- Python
- Flask

Frontend

- HTML5
- CSS3
- JavaScript

Database

- SQLite

Installation

1. Clone the repository

git clone https://github.com/komezimihigo/SwiftType-.git

2. Navigate to the project directory

cd SwiftType-

3. Create a virtual environment

python -m venv venv

4. Activate the virtual environment

Windows:

venv\Scripts\activate

Linux/macOS:

source venv/bin/activate

5. Install dependencies

pip install -r requirements.txt

6. Run the application

python app.py

7. Open your browser and visit:

http://127.0.0.1:5000
